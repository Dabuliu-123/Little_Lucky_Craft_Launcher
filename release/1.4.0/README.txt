LLcl 1.3.0 - 极简 Minecraft Java 启动器（发行版）

系统要求
- Windows 7 / 8 / 10 / 11（64 位）
- 无需 .NET、无需预装 Java；启动器会在需要时自动下载对应 Java（需要联网）
- 单个 LLcl.exe 约 421KB，空闲内存约 2.3MB，启动峰值约 15MB

首次使用
1. 双击 LLcl.exe。
2. “设置”里确认游戏目录（默认是 exe 同级的 .minecraft，首次启动会自动创建）。
3. 列表里没有游戏版本时，点“下载与安装”，选择版本安装（自带资源、库和对应 Java）。
4. 选中版本，点“启动游戏”。

远程联机（1.3.0 新增，像 Radmin LAN 一样进游戏 LAN 列表）
主机：
1. 进入世界，按 Esc → “对局域网开放”。
2. 启动器点“远程联机（房间 / 服务器）”，选“直连”或“中转”。
   - 直连：端口留空会自动从游戏日志读取；能 UPnP 的路由器会自动开端口。
     外网玩家连不上时，需要在路由器把 TCP 端口映射到本机。
   - 中转：需要一台可被双方访问的机器运行中转服务器：
         LLcl.exe --relay 25566
     然后在“中转服务器”里填 该机器IP:25566。
3. 点“创建房间”，点“复制邀请码”发给朋友。
玩家：
1. 打开“远程联机”，粘贴邀请码，点“加入房间”。
2. 打开 Minecraft → 多人游戏，局域网列表会出现房间；也可以“直接连接”
   邀请码/界面上显示的 127.0.0.1:端口。
3. 联机期间保持启动器运行；关掉启动器会断开房间。

常用功能
- 下载与安装：游戏本体 + 资源 + 自动 Java，也能安装 Fabric / Quilt / Forge / NeoForge。
- 内容中心：Mod / 光影 / 资源包 / 整合包；支持安装本地 .mrpack。
- 版本管理：查看并管理所选版本的 模组 / 光影 / 数据包；支持添加本地模组、
  启用/禁用（.disabled）、删除、打开文件夹，可一次禁用/启用全部。
- 账号与登录：离线玩家名在“设置”修改；支持微软正版设备码登录，启动时自动续期。
- 磁盘清理：清理 logs、crash-reports、下载缓存、JVM 崩溃残留。
- 版本隔离：开启后每个版本的存档 / 模组 / 配置独立在 versions/<版本>/instance。
- 服务器列表：读写 servers.dat，支持局域网扫描、添加/删除/直连启动。

注意事项
- 远程联机是应用层 TCP 代理 + LAN 公告，不安装虚拟网卡/驱动；因此不需要管理员权限，
  但直连模式依赖主机可被访问（公网 IP / UPnP / 端口映射）。
- 中转服务器是明文 TCP，只应提供给朋友使用；房间码 + 令牌用于防误入。
- 首次下载 26.x 需要较多资源文件（约 400MB+），请保持网络畅通。
- 如果杀毒软件/防火墙拦截，请把 LLcl.exe 加入信任并允许专用网络入站；
  启动器只访问 Mojang / BMCLAPI / Modrinth / 微软登录接口（以及你填写的中转服务器）。
- 配置保存在 exe 同级的 LLcl.ini，删除它即可恢复默认设置。
- 游戏日志在 <游戏目录>\logs\llcl-launch.log。
